# MorganBioPilot

Agentic retrobiosynthesis: an LLM agent as search policy on top of a
deterministic expansion engine in ECFP fingerprint space.

Node expansion is symbolic and reproducible — applicability prefiltering via the
reaction-center ECFP, graph-level validation, precursor generation. The agent
decides strategy only: which frontier node to expand next, and at which rule
diameter, i.e. how much enzymatic promiscuity to assume.
